Amber is only for key words. A warning is a neutral banner with an icon and a word, so the eye never mixes the two.

No red during a session. Problems are worded calmly. Danger is for deleting and removing, which happen outside a session.

Never color alone. Every status pairs an icon with a word, so it reads in grayscale and to a screen reader.

04

Answers

Plain Markdown, written to be said aloud. Short first-person paragraphs; key words are the Markdown's bold italic, drawn amber, semibold and upright, two or three a paragraph. Nothing else: no tables, no images, no links that open (§7.3).

Tell me about a time you disagreed with a teammate.

Spoken

Sure. So at Northwind I was on the payments team, and a teammate wanted to rewrite our retry logic right before a release.

I thought that was risky, so instead of arguing in the channel I set up a quick call, and we went through the failure cases together. We found two bugs in the old code, fixed those first, and planned the rewrite for the next sprint.

The release went out on time, and the rewrite later cut duplicate charges a lot.

Consistent hashing

Study

What it is. A way to spread keys over servers so that adding or removing one moves only a few keys.

  • The ring. Servers and keys are hashed onto the same circle; a key belongs to the next server clockwise.
  • Virtual nodes. Each server appears many times on the ring, which evens out the load.
  • Where you'll meet it. Caches, sharded databases, load balancers.

Code

Python
from collections import Counter
 
def first_unique(s: str) -> str | None:
    # two passes: count, then find a count of one
    counts = Counter(s)
    for ch in s:
        if counts[ch] == 1:
            return ch
    return None
 
print(first_unique("swiss"))

Blocks sit on their own background with the language named, and Copy. Lines never wrap: a long line scrolls inside its block. Inline code sits in the sentence: swap the hint for Optional[str]. No amber in code.

Motion

Hover and press: 120 ms. Menus fade in over 160 ms. Answers and Heard grow in place, with no animation, and never move the line being read. Two things move by themselves: the listening meter and the writing dot. With reduced motion on, neither does. Nothing flashes, shakes or makes a sound.
